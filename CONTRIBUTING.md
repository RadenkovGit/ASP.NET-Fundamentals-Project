# Contributing

Thanks for your interest in improving this project! This is a small ASP.NET
Fundamentals learning project, so contributions are welcome to stay simple and
focused.

## Reporting issues

- Open a GitHub issue describing the bug, question, or improvement you have in
  mind. Include enough detail (steps to reproduce, expected vs. actual
  behavior, screenshots) for someone else to understand the problem quickly.

## Proposing changes

1. Open an issue first for anything non-trivial, so the approach can be agreed
   on before work starts.
2. Fork or branch the repository and make your changes.
3. Keep pull requests focused on a single change or fix.
4. Open a pull request describing what changed and why, and link back to the
   issue it addresses.

## Getting AI-assisted help

This repository uses the [`@claude` GitHub Action](https://github.com/anthropics/claude-code-action)
to assist with issues and pull requests. You can mention `@claude` in an issue
or PR comment to ask for help, a code review, or an implementation of a
requested change, and it will respond directly in the comment thread.

## Code style

Follow the existing conventions in the codebase (naming, formatting, and
project structure) when making changes, and keep commits small and
descriptive.
